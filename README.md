Healthcare Management Web Application
About the Project

Health+ is a healthcare web application developed using React.js with the aim of making healthcare services more accessible and convenient. The platform allows users to explore doctors, check their details and reviews, and book appointments through a simple and user-friendly interface.

This project was created to demonstrate frontend development skills, responsive design, form validation, and React component management while solving a real-world healthcare problem.

Features
👨‍⚕️ Doctor Directory

Users can browse a list of doctors along with their specialties, ratings, and reviews to make informed decisions before booking appointments.

📅 Appointment Booking

Patients can book appointments by entering their details, selecting a preferred date and time, and choosing between voice or video consultation.

✅ Form Validation

The application validates user inputs such as name, phone number, appointment date, and required fields to ensure accurate information is submitted.

💬 Patient Reviews

A review section allows users to view feedback from previous patients through an interactive testimonial carousel.

🔔 Notificationsj

Toast notifications provide instant feedback whenever an appointment is booked or a newsletter subscription is completed.

📧 Newsletter Subscription

Users can subscribe to healthcare updates through an email validation system.

📱 Responsive Design

The application is fully responsive and works smoothly across desktop, tablet, and mobile devices.

❌ Custom 404 Page

A custom error page handles invalid routes and improves the overall user experience.
